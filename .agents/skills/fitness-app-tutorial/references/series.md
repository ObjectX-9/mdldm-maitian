# 「今日建议怎么看？」系列规范

## 录制与镜头清单

- Mac 镜像窗口录制可用 `/usr/sbin/screencapture -v -k -x -l"$window_id" -V"$seconds" "$take"`。先获取当前窗口 ID，再短录核对窗口选择、屏幕录制权限和光标是否入镜。窗口捕获不可用时，用 macOS 屏幕录制的选区扣紧镜像画面。保留清洁录屏，手机外框在后期合成。
- 稀疏预览可按 1–2 fps 取帧。定位单个动作时用 `ffmpeg -ss "$time" -i "$take" -frames:v 1 "$frame"` 取指定时间点，按实际源帧细化切点和覆盖位置。保留带时间码的关键帧或截图编号，方便回查。
- 一条镜头记录可写成「展开今日建议 → 原片点击时刻与稳定结果时刻 → 成片点击时刻与气泡、字幕区间 → 控件框 `[x, y, w, h]` → 琥珀气泡‘展开’ → 拉近、红圈定格、点击闪光 → 中文旁白与对应英文」。坐标按裁切后的手机有效画面归一化至 0–1。示例动作顺序为今日页 → 点「展开」→ 滑动查看肌群恢复与训练安排。每期重新定位事件和截图。
- 坐标随画幅和运镜转换。先把归一化位置换算到成片里手机有效画面的矩形，再应用该帧的缩放、位移与裁切。时间映射来自实际保留片段和插入定格，删除区间内的标记不带进成片。

## 视频风格

- 黑白灰基底，左上角圆形猫咪徽标与「健身猫」字标。「健身」为黑色，「猫」为品牌绿 `#117854`。视频样片的圆徽标源图来自健身猫工程的 `apps/mobile/assets/agent-roles/coordinator-cutout.png`，默认本机工程目录是 `~/Documents/objectX/fitness-plan`。优先使用已有品牌锁定素材。
- 标题用已选的 D「前倾运动黑」。竖版标题在顶部，手机画面在下；B 站横版手机在左、标题区在右。按各画幅布局，检查运镜中标题和品牌是否被遮住。
- 操作提示用 A「圆角尖尾」气泡，琥珀色 `#FFD186`。关键点击采用三次贝塞尔平滑拉近、红圈定格约 1 秒、点击时指针轻闪，再平滑缩回。按镜头调整倍率、停留与提示位置；继续浏览或滑动时保留真实手势。
- 旁白默认使用上次选定的百炼女声「干练快讲」：模型 `qwen-audio-3.1-tts-flash`，音色 `longanli_v3.1`。标准普通话，短句直接、操作词清楚，动作之间留半拍。凭证由运行环境读取。字幕按句与旁白对齐，底部中文在上、英文在下。
- 默认导出 MP4，H.264 视频和 AAC 音频。小红书 1080×1440，抖音 1080×1920，B 站 1920×1080。视频和封面分别构图。

## 封面风格

- 暖白纸纹、黑色前倾大标题和琥珀色标题底块，肥特贴纸靠近标题，银色手机展示真实关键 UI 帧。标记只突出本期要操作的控件。以「今日建议／怎么看？」作标题分行参考，新一期使用本期功能名称。
- 保留[已确认的封面图标和字标](../assets/cover-brand.png)的原始图形与颜色。在旁边放独立的「教程」标签。使用 ImageGen 时先生成构图、纸纹或贴纸区域，保留品牌区，最终直接叠合原品牌素材与真实 App 截图。样本品牌块带暖白底，放在同类底纹上，可融合外缘，保持图标和字标像素区域完整。
- 小红书竖版 3:4（可用 1080×1440），抖音竖版 3:4（1080×1440）和横版 4:3（1440×1080），B 站横版 4:3（1200×900）。按画幅分别构图。若本次投稿界面明确要求其他尺寸，按该入口设置导出。
