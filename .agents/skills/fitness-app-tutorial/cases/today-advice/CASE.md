# 今日建议怎么看？

健身猫功能教程案例。演示从「今日」页点「展开」查看今日建议，再向下滑查看肌群恢复与训练安排。以下素材可用于对照下一期的版式、操作节奏和提示样式。

## 视频与封面

| 平台 | 成片 | 封面 |
| --- | --- | --- |
| 小红书 | [3:4 · 1080×1440](video/小红书-3比4.mp4) | [3:4 肥特贴纸稿](covers/小红书-贴纸稿-3比4.png) |
| 抖音 | [9:16 · 1080×1920](video/抖音-9比16.mp4) | [3:4 竖封面](covers/抖音-竖封面-3比4.png) · [4:3 横封面](covers/抖音-横封面-4比3.png) |

三版成片均为 10.2 秒、30 fps，使用 H.264 视频和 AAC 音轨。抖音两张封面使用相同的[原版品牌图块](../../assets/cover-brand.png)，单独显示「教程」标签。小红书和 B 站保留本次制作过程中已有的封面版本。

## 音色

[「干练快讲」音色试听](voice/干练快讲-试听.mp3) · [成片实际音轨](voice/成片音轨.m4a)

百炼模型 `qwen-audio-3.1-tts-flash`，音色 `longanli_v3.1`。本次使用标准普通话、稍快语速，清楚重读「展开」和「向下滑」，两步间轻停，句尾收短。

## 动效和提示气泡

| 元素 | 本次用法 |
| --- | --- |
| 镜头推拉 | 用三次贝塞尔平滑拉近到 1.72 倍，近景定格 30 帧，再平滑缩回。保留[运镜关键帧](motion/运镜关键帧.jpg)和[原始贝塞尔曲线表达式](motion/原始贝塞尔曲线.sh)。 |
| 红圈和点击 | 红圈标住「展开」，在点击时配合短促的指针闪光。原始透明 PNG 序列按 30 fps 排列于 `motion/red-ring/` 和 `motion/click-spark/`。 |
| [点「展开」](tip/点展开.png) | 成片 0.54–1.62 秒，尖尾朝下指向控件。105 ms 淡入、120 ms 淡出。 |
| [恢复详情](tip/恢复详情.png) | 成片 5.08–7.20 秒，尖尾朝左指向圆形标记。140 ms 淡入、200 ms 淡出。 |

两枚提示用 A「圆角尖尾」造型，底色 `#FFD186`、高光描边 `#FFE1AA`、文字 `#442910`。气泡淡入时向上移动 7 px。所存 PNG 为小红书版实际贴图。时间均以成片为准，下一期按新录屏重新对齐。

## 文字与字幕

- 片头标题为「查看今日建议与恢复状态」，使用[字体对比稿](text/标题字体对比.png)里的 D「前倾运动黑」。
- 封面标题分两行「今日建议」「怎么看？」。品牌字标是「健身猫」，抖音封面旁边另放「教程」。
- [双语字幕 SRT](text/中英双语字幕.srt)保留实际成片的文案与时间。样式是底部深灰圆角字幕条，中文白字在上，英文浅灰字在下。中文使用 Hiragino Sans GB，英文使用 Helvetica Neue。 [第一句贴图](text/双语字幕-01.png) · [第二句贴图](text/双语字幕-02.png)
