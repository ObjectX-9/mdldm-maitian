# 「今日建议怎么看？」三平台发布文案

## 抖音

**标题｜今天练不练？先点开「今日建议」**

准备开练了，还在纠结今天该练还是该休息？打开健身猫，在「今日」页找到「今日建议」，点右下角的「展开」，再往下滑，就能看到肌群恢复状态和接下来的训练安排。下次开练前，先看一眼。

## 小红书

**标题｜今天练什么？健身猫「今日建议」教程**

昨天练完腿，今天还能接着练吗？或者打开 App 想开练，却不知道从哪看恢复状态和训练安排？这条教程带你走一遍。

📍操作路径  
打开健身猫 →「今日」→ 找到「今日建议」→ 点右下角「展开」→ 往下滑

展开后可以先看今天的建议。继续往下滑，「肌群恢复度」会显示哪些肌群恢复较充分、哪些还在恢复；再往下就是接下来的训练安排。

想查得更细，可以点「查看恢复详情」。收藏这条，下次开练前照着点一遍。
