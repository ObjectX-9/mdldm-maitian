从抖音和小红书的健身、运动健康内容中找选题。记录代表性的短视频截帧、图文与评论，分析内容如何呈现，以及用户反复提到哪些问题。

## 什么时候用

- 每日热点采集、缺漏补采或已有批次复盘。
- 调研健身 App、独立开发者帖子和用户在评论里提出的需求。

## 交付什么

把样本、素材和分析写入本地研究库，汇总可做的内容选题、产品机会和证据缺口，供麦田工作台浏览。
